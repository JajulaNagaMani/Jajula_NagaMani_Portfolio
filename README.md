# Jajula NagaMani — Netlify Portfolio

This is a Netlify-ready static portfolio inspired by the overall structure and feel of the reference portfolio you provided.

## Important
- The ONLY human photo included is `profile.jpg`, the photo you uploaded.
- No stock people/photos are used.
- Project visuals are CSS-built UI illustrations, not photographs.
- `resume.pdf` is included when available.

## Deploy on Netlify
1. Extract this ZIP.
2. Open Netlify.
3. Choose **Add new project / Deploy manually** (wording may vary).
4. Drag the extracted project folder into the deploy area.
5. Netlify will generate a `*.netlify.app` URL.

You can later change the Netlify site name in the site settings if the desired name is available.

## Local preview
Open `index.html` in a browser.
